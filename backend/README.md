# Code — Backend

واجهة برمجية خلفية لمنصة "Code" مبنية على NestJS + TypeScript + PostgreSQL (Prisma) + Redis + Socket.IO.

## المراحل المنجزة

**Phase 1 — المصادقة ونظام وكالات الشحن**
- المصادقة (Auth): تسجيل، دخول (بريد/هاتف/اسم مستخدم)، JWT + Refresh Token، إدارة الجلسات، تسجيل الخروج من جميع الأجهزة، تغيير كلمة المرور، المصادقة الثنائية (2FA/TOTP)، قفل الحساب بعد محاولات فاشلة، سجل تسجيل الدخول، تنبيه عند جهاز جديد.
- نظام وكالات الشحن (Recharge Agency System) كاملاً: تقديم طلب فتح وكالة ومراجعته، إنشاء الوكالة والمحفظة تلقائيًا عند الموافقة، وكلاء فرعيون وتوزيع الرصيد، طلبات تعبئة الرصيد ومراجعتها، شحن المستخدمين (Idempotency + حدود يومية + عمولات)، طلبات سحب الأرباح، إعدادات قابلة للتعديل من لوحة الإدارة.

**Phase 2 — الغرف الصوتية والرسائل الخاصة**
- الغرف الصوتية: إنشاء/تعديل/حذف، انضمام بكلمة مرور اختيارية، إدارة المقاعد (أخذ/ترك/كتم/قفل)، صلاحيات Owner/Co-Owner/Admin/Moderator/Member، طرد/حظر/تغيير الصلاحية، سجل أحداث كامل.
- الرسائل الخاصة: محادثات 1:1 نصية مع رد/تعديل/حذف/إعادة توجيه، إشعارات قراءة، تثبيت/كتم، بحث، حظر مستخدم، إبلاغ.
- بث لحظي عبر Socket.IO (namespaces: `/rooms`, `/messaging`) لكل التغييرات.

**Phase 3 — المحفظة، الهدايا، ولعبة الرهان**
- محفظة كل مستخدم (ذهب/ألماس) تُنشأ تلقائيًا.
- عند شحن الوكيل لمستخدم، يُضاف الذهب فعليًا لمحفظته (بمعدل `goldPerCurrencyUnit` القابل للتعديل من لوحة الإدارة) — هذا يربط نظام وكالات الشحن بباقي النظام.
- الهدايا: كتالوج هدايا (ثابتة ومحظوظة) تُدار من لوحة الإدارة، إرسال هدية (يخصم الذهب من المرسل، يضيف ألماس للمستقبل)، الهدايا المحظوظة تسحب مضاعفًا عشوائيًا (Weighted Random) يُرجع ذهبًا للمرسل، سجل الهدايا.
- لعبة رهان "تخمين الرقم" (Dice Guess): رهان بمبلغ ذهب واختيار رقم 0-9، نتيجة عشوائية آمنة (crypto RNG)، حدود رهان يومية ودنيا وعليا قابلة للتعديل.
- كل من الهدايا والألعاب قابلة للتشغيل داخل غرفة صوتية (roomId اختياري) وتُبث لحظيًا لجميع أعضاء الغرفة عبر Socket.IO.

## غير منجز بعد

VIP، الوكالات الاجتماعية (Content Agencies)، سحب رصيد الألماس للمستخدمين العاديين، اختبارات E2E شاملة، مراقبة أداء إنتاجية.

## التشغيل

```bash
cp .env.example .env
npm install
npx prisma migrate dev
npm run prisma:seed   # ينشئ حساب Owner افتراضي
npm run start:dev
```

Swagger: `http://localhost:3000/api/docs`
