# Code — Backend

واجهة برمجية خلفية لمنصة "Code" مبنية على NestJS + TypeScript + PostgreSQL (Prisma) + Redis.

## المرحلة المنجزة (Phase 1)

- المصادقة (Auth): تسجيل، دخول (بريد/هاتف/اسم مستخدم)، JWT + Refresh Token، إدارة الجلسات، تسجيل الخروج من جميع الأجهزة، تغيير كلمة المرور، المصادقة الثنائية (2FA/TOTP)، قفل الحساب بعد محاولات فاشلة، سجل تسجيل الدخول، تنبيه عند جهاز جديد.
- نظام وكالات الشحن (Recharge Agency System) كاملاً:
  - تقديم طلب فتح وكالة ومراجعته (قبول/رفض/طلب تعديل/تعليق).
  - إنشاء الوكالة والمحفظة ومنح صلاحية Recharge Agent تلقائيًا عند الموافقة.
  - إنشاء وكلاء فرعيين وتوزيع الرصيد عليهم من قبل Master Recharge Agency.
  - طلبات تعبئة الرصيد (مع أو بدون إثبات دفع) ومراجعتها، بالإضافة إلى تعبئة يدوية مباشرة.
  - شحن المستخدمين مع حماية من التكرار (Idempotency)، حدود يومية، احتساب وتوزيع العمولات (وكيل/وكالة/تطبيق)، ومراجعة تلقائية للعمليات الكبيرة عبر Audit Log.
  - طلبات سحب الأرباح ومراجعتها.
  - لوحة إحصائيات للوكيل وللوكالة.
  - إعدادات عمولات وحدود قابلة للتعديل من لوحة الإدارة دون تعديل الكود.
- الإشعارات وسجل التدقيق (Audit Log) لكل العمليات الحساسة.

## غير منجز بعد

الغرف الصوتية، الرسائل الخاصة، الهدايا والعملات الداخلية للمستخدمين العاديين، VIP، الألعاب، الوكالات الاجتماعية (Content Agencies). لذلك عملية "شحن المستخدم" حاليًا تُنشئ سجل العملية وتخصم من محفظة الوكيل وتحتسب العمولات، لكن إضافة الرصيد الفعلي داخل تطبيق المستخدم مرتبطة بنظام العملات الذي سيُبنى في مرحلة لاحقة.

## التشغيل

```bash
cp .env.example .env
npm install
npx prisma migrate dev
npm run prisma:seed   # ينشئ حساب Owner افتراضي
npm run start:dev
```

Swagger: `http://localhost:3000/api/docs`
