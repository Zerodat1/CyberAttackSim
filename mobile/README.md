# Code — Mobile

تطبيق الجوال لمنصة "Code" مبني على React Native (Expo) + TypeScript.

## المرحلة المنجزة (Phase 1)

- تسجيل الدخول / إنشاء حساب مع تجديد الجلسة تلقائيًا (Refresh Token).
- التقديم لفتح وكالة شحن ومتابعة حالة الطلب.
- لوحة وكالة الشحن: الرصيد المتاح، إحصائيات الشحن اليومي/الأسبوعي/الشهري، الأرباح والعمولات.
- شحن مستخدم عبر إدخال ID المستخدم واختيار مبلغ الشحن.
- تقديم طلب سحب الأرباح.

## التشغيل

```bash
npm install
npx expo start
```

اضبط متغير البيئة `EXPO_PUBLIC_API_URL` ليشير إلى عنوان الـ backend (افتراضيًا `http://localhost:3000/api/v1`).
